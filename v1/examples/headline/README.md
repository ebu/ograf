# Reference: Headline

This lower-third example displays a configurable category tag and headline.

The Graphic is designed for a 1920 x 1080, 50 fps output. It supports real-time
and non-real-time rendering and exposes one play step.

The package was exported with [StreamShapers OGraf Builder](https://streamshapers.com/ograf-builder).
All runtime assets, including the local Lottie player, are included in this directory.
