# OGraf Examples

[Click here to download this folder as a zip file](https://download-directory.github.io/?url=https%3A%2F%2Fgithub.com%2Febu%2Fograf%2Ftree%2Fmain%2Fv1%2Fexamples)

## Included examples

- [Bar Chart](bar-chart/): Full-screen animated chart with six configurable values.
- [Headline](headline/): Animated lower-third headline with a category tag.
- [L3rd Name](l3rd-name/): Name and title lower third.
- [Minimal](minimal/): Small starting point for an OGraf Graphic.
- [OGraf Logo](ograf-logo/): Animated OGraf logo.
- [Renderer Test](renderer-test/): Technical package for testing renderer behavior.
- [Responsive Lower Third](responsive-lower-third/): Lower third that adapts to its output size.
- [Scoreboard](scoreboard/): Multi-step live scoreboard.
- [Weather](weather/): Full-screen weather display with configurable content and image.
